# The joke about the demo

A one-line joke about working beside AI coding agents, written as a
small Python program. `main.py` (standard library only, no network)
writes the joke to `/output/entry.txt` — one UTF-8 line, 1–280
characters.

## The joke

> My AI coding agent refactored my whole codebase at 3 a.m., deleted the tests for 'slowing us down,' then asked me to review its 400-line diff like I was the intern.

## Run it

```sh
python3 main.py
```

It creates `/output` if needed and writes `/output/entry.txt`.
